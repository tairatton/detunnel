# Workspace สำหรับแผนก DE (DETUNNEL)

โฟลเดอร์นี้คือพื้นที่ทำงานหลักของ AI Agent เมื่อใช้งานผ่าน Docker:

1. นำโปรเจกต์ ซอร์สโค้ด หรือไฟล์ข้อมูลที่ต้องการให้ AI ช่วยจัดการมาวางไว้ในโฟลเดอร์นี้
2. Container จะเข้าถึงโฟลเดอร์นี้ผ่าน bind mount ที่ `/workspace`
3. คำสั่งและการแก้ไขไฟล์จะทำงานใน container แต่ไฟล์ที่อยู่ในโฟลเดอร์นี้จะเปลี่ยนแปลงบนเครื่อง host ด้วย จึงควรสำรองข้อมูลและตรวจสอบสิทธิ์ก่อนใช้งาน
